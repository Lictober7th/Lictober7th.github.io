# GIF 粒子动画

这是一个基于 Canvas 和物理模拟的 GIF 粒子展示工具。它会将指定的 GIF 图像逐帧采样为粒子点阵，每个粒子都带有弹回、阻尼以及鼠标排斥的物理效果，形成动态的流动感。在我的GITHUB上可以找到。

---

## 效果预览

- 加载 `drive.gif` 后，自动将每一帧转换为粒子矩阵。
- 粒子会受鼠标光标影响（排斥力），鼠标移开后粒子逐渐弹回原位。
- 粒子颜色可通过 CSS 变量轻松修改。
- 支持透明背景，适合叠加到其他页面或桌面壁纸场景。

## 使用方法

1. 准备一张 GIF 图片，命名为 `drive.gif`，放在与 `index.html` 相同的目录下。
2. 用现代浏览器（Chrome/Edge/Firefox 等）打开 `index.html`。
3. 页面会自动解析 GIF 的每一帧，并渲染为粒子动画。
4. 移动鼠标到画布上，粒子会受到排斥力而散开，移开鼠标后粒子会缓慢弹回原位。

---

## 配置参数

您可以在 `index.html` 的 JavaScript 代码顶部（约第 30~40 行）调整以下参数，以改变粒子的外观和物理行为：

| 参数 | 说明 |
|------|------|
| `STEP` | 采样步长，每 `STEP` 个像素取 1 个粒子。值越大粒子总数越少（总数为 1/STEP²）。 |
| `Q`   | 粒子大小系数（半径 = `STEP * Q`）。 |
| `R`   | 鼠标排斥半径（像素），鼠标在该半径内会对粒子产生排斥力。 |
| `P`   | 排斥力强度，值越大排斥越明显。 |
| `K`   | 弹回力强度，控制粒子回归原始位置的弹簧系数。 |
| `D`   | 阻尼系数（0~1），值越小粒子运动越“粘滞”。 |
| `M`   | 图像最大尺寸限制（像素），若 GIF 宽或高超过该值会自动等比例缩小。 |

## 自定义粒子颜色

粒子默认颜色为黑色（`#000000`），您可以通过 CSS 变量轻松修改：

在 `<style>` 中的 `:root` 选择器里，修改 `--particle` 的值即可。例如：

```css
:root {
    --particle: #ff6b6b;  /* 改为红色 */
}
```

您也可以动态修改该变量（如通过浏览器开发者工具），动画会自动应用新颜色。

## 浏览器兼容性

- 需要使用支持 `ImageDecoder` API 的现代浏览器（Chrome 86+、Edge 86+、Firefox 113+ 等）。
- 不支持旧版 IE 或 Safari 早期版本。

如果浏览器不支持，页面会提示“浏览器版本过低”。

---

## 注意事项

- 页面尺寸在首次加载时根据视口和 GIF 尺寸自适应计算，**窗口缩放或 resize 后不会重新调整**，如需适配请刷新页面。
- GIF 帧的时长信息会被读取并用于控制帧切换速度，若 GIF 未提供持续时间，默认每帧显示 80ms。
- 如果无法加载 `drive.gif`，页面会显示提示文字，请确保文件存在且命名正确。
