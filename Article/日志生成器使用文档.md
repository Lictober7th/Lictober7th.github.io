# 日志生成器使用文档

## 📋 简介

日志生成器是一个基于 Python Tkinter 开发的图形界面工具，专门用于管理和生成符合 Lictober7th 博客系统格式的日志数据。它可以扫描目录中的 Markdown 文件，并通过直观的界面编辑帖子信息，最终保存为 `manifest.json` 配置文件。

---

## ✨ 主要功能

### 1. 文件管理
- **自动扫描**：启动时自动扫描当前目录下所有 `.md` 文件
- **刷新列表**：手动刷新 `.md` 文件列表，方便添加新文件后更新
- **下拉选择**：从扫描到的文件列表中选择目标文件

### 2. 帖子信息编辑
- **文件名**：从下拉列表中选择已有的 `.md` 文件
- **标题**：设置帖子的显示标题
- **时间**：自动填充当前时间，支持一键更新
- **分类**：支持开发(dev)、游戏(game)、考据(lore)、其他(other)四种分类
- **大标签**：自定义分类标签
- **标签**：支持多个标签，用逗号分隔
- **摘要**：帖子的简要描述
- **精选**：标记是否为精选内容

### 3. 数据管理
- **添加/更新**：添加新帖子或更新现有帖子
- **删除**：删除选中的帖子
- **清空表单**：清空输入表单，保留文件名选择
- **清空所有**：清空所有帖子数据（需确认）

### 4. 数据持久化
- **自动加载**：启动时自动加载 `manifest.json` 文件
- **手动保存**：点击按钮保存数据到 `manifest.json`
- **状态提示**：实时显示操作状态和帖子数量

## 🚀 快速开始

### 系统要求
- Python 3.6 或更高版本
- Tkinter（Python 标准库，通常已预装）

### 安装依赖
本项目仅使用 Python 标准库，无需额外安装依赖。

### 启动程序
```bash
python log_generator.py
```

### 首次使用
1. 确保程序所在目录有 `.md` 文件（或手动创建）
2. 启动程序，自动扫描 `.md` 文件
3. 如果没有 `manifest.json`，程序会自动创建
4. 开始添加帖子信息

### 操作流程

#### 添加新帖子
1. 从"文件名"下拉框选择对应的 `.md` 文件
2. 填写帖子标题
3. 点击"当前时间"自动填充时间（可选）
4. 选择分类（默认为"开发"）
5. 填写大标签（可选）
6. 填写标签（用逗号分隔，如：`Python, JSON, 日志`）
7. 填写摘要（可选）
8. 勾选"设为精选"（可选）
9. 点击"添加/更新帖子"

#### 编辑现有帖子
1. 在帖子列表中单击选中要编辑的帖子
2. 表单会自动填充该帖子的所有信息
3. 修改需要更新的字段
4. 点击"添加/更新帖子"完成更新

#### 删除帖子
1. 在帖子列表中单击选中要删除的帖子
2. 点击"删除当前帖子"
3. 确认删除操作

#### 保存数据
1. 完成所有编辑后
2. 点击"保存到 manifest.json"
3. 数据将写入程序所在目录的 `manifest.json` 文件

## 📁 文件格式说明

### manifest.json 结构
```json
{
  "title": "日志",
  "subtitle": "Lictober7th://LOG",
  "posts": [
    {
      "file": "2024-01-01-hello-world.md",
      "title": "Hello World",
      "date": "2024-01-01 12:00:00",
      "cat": "dev",
      "catLabel": "开发",
      "tags": ["Python", "教程"],
      "excerpt": "这是我的第一篇博客文章",
      "featured": false
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `file` | string | ✅ | 对应的 `.md` 文件名（含扩展名） |
| `title` | string | ✅ | 帖子显示标题 |
| `date` | string | 否 | 帖子时间，格式：`YYYY-MM-DD HH:MM:SS` |
| `cat` | string | 否 | 分类代码：`dev`/`game`/`lore`/`other` |
| `catLabel` | string | 否 | 大标签（自定义分类标签） |
| `tags` | array | 否 | 标签数组 |
| `excerpt` | string | 否 | 帖子摘要 |
| `featured` | boolean | 否 | 是否精选（`true`/`false`） |

## 🎯 使用技巧

### 1. 批量操作
- 可以一次性添加多个帖子，最后统一保存
- 使用"清空表单"快速重置输入，开始添加下一个帖子

### 2. 文件管理
- 新创建的 `.md` 文件需要点击"刷新列表"才能显示
- 文件名下拉框只显示 `.md` 文件，确保文件格式正确

### 3. 数据安全
- 保存前请确保数据完整
- 建议定期备份 `manifest.json` 文件
- 删除操作不可恢复，请谨慎操作

### 4. 标签规范
- 使用英文逗号分隔多个标签
- 标签会自动去除前后空格
- 空标签会被自动过滤

## ❓ 常见问题

### Q: 启动时提示找不到 `manifest.json`？
**A**: 这是正常现象，程序会自动创建新的 `manifest.json` 文件，不影响使用。

### Q: 下拉框中没有显示我的 `.md` 文件？
**A**: 请点击"刷新列表"按钮手动刷新，确保 `.md` 文件在程序所在目录。

### Q: 保存数据时提示权限错误？
**A**: 请确保程序有写入权限，或检查文件是否被其他程序占用。

### Q: 添加帖子时提示"文件名和标题不能为空"？
**A**: 请确保选择了有效的 `.md` 文件并填写了标题。

### Q: 如何修改已保存的数据？
**A**: 在帖子列表中点击选择要修改的帖子，表单会自动填充，修改后点击"添加/更新帖子"即可。
